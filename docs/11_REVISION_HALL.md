## 結構：課題 → 篇章 → 卡 → 練習
| 卡號 | 內容 | 來源段落 |
|---|---|---|
| `A11-01` 概念 | 概念與關鍵字（或先解決一個問題、從問題選函數等） | 原文 |
| `A11-02` 例子 | 原創例子／公式及結果／情境比較 | 原文 |

卡號固定，日後加入實驗室不會令舊進度錯位。內容與進度分開：進度存於存檔 `profile.revision`，不寫回教材。

## 首頁
- 主頁「📚 知識修練館」橫額：有到期卡時顯示數目，否則顯示接續的篇章。
- 修練館首頁三個入口：接續上次、今日需複習、按課題探索；另有關鍵字搜尋（篇章編號、標題、關鍵字、內文）。
- 「字」按鈕切換三級字體大小。正誤除顏色外亦有 ✓／✕ 文字；所有按鈕可用鍵盤操作；裝置設定「減少動態效果」時不播放動畫。

## 互動及正確性
- Excel：`src/core/excel.js` 真正計算公式（SUM、AVERAGE、MAX、MIN、COUNT、COUNTA、COUNTIF、SUMIF、IF、AND、OR、NOT、LEFT、RIGHT、MID、LEN、INT、ROUND、SQRT、RANK、TEXT、VLOOKUP、HLOOKUP、XLOOKUP），包括相對／絕對參照複製。精確配對找不到時顯示 #N/A，不會暗中改用近似配對。
- Python：`src/core/pytrace.js` 只執行筆記內附的短程式（不開放輸入任意程式），逐行記錄高亮行、變量及輸出；有 2000 步上限防止無限循環。所有篇章內的 Python 例子都有「▶ 逐步追蹤」。
- 測試（`tests/excel.test.js`、`tests/pytrace.test.js`）自動核對：A10–A13 每條公式表的結果、A09 參照複製、所有 Python 例子的輸出，以及驗收要求（A10 350／70／242、A11 60 及 2 次獲獎而 59 不獲獎、A12 INT(-8.1)=-9 及 MID 得 "57"、A13 精確查找 72 得 #N/A 而近似得「熟練」、D05 85 分 Gold、D06 2、4、6、8 總和 20、D09 首個配對 1 及找不到 -1）。

## 三個試點實驗室
| 實驗室 | 任務 |
|---|---|
| A11 獲獎條件實驗室 | 先預測 P104 → 改分數及次數即時重算（顯示每個條件的 TRUE／FALSE）→ 找出把 >= 寫成 > 的邊界錯誤 → 新例子（隨機邊界數據，引擎計算答案） |
| D11 追蹤表挑戰 | 先預測輸出 → 逐步追蹤及追蹤表 → 改條件 x >= 7 → 新數據（追蹤器計算答案及錯誤選項）→ 測試數據分類（10 至 20 的整數） |
| C07 身份認證情境 | 因素分類 → 判斷是否 MFA（兩種不同類別）→ 認證還是授權 → 按問題選防護措施 |

選項中的錯誤答案來自常見錯誤（例如 > 與 >= 對調、計算全部項目）。所有事實及措辭取自筆記；只有新例子的數字是隨機產生，並由引擎重新計算。

## 進度、複習及獎勵
- 卡片狀態：未學、練習中、待複習、已鞏固。
- 複習間隔 1、3、7、14 日（`REVISION_RULES.intervalsDays`，可調）：到期答對向後推一級；答錯回到第一級，並即時列入「今日需複習」。
- 經驗值：第一次完成 +5；新例子答對 +10；修正之前的錯誤 +15；到期複習答對 +20。每張卡每日（香港時間）最多 +30。
- 自測由學生自評，只用來安排複習，除第一次完成外不給經驗，避免誘使學生虛報。
- 答錯不扣血、不鎖閱讀，並提供「補回概念」連結（概念卡及易錯卡）；作答紀錄會保留。
- 重開頁面可「接續上次」。
