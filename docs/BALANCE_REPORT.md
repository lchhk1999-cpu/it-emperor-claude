# 數值平衡報告（P6-01）

狀態：CONFIRMED 並已套用（2026-10-31，用戶：「套用建議數值」）。SSR 保底 50 需由 ChatGPT 同步 Excel `Pools` 表（CHAR-STD SSR pity_threshold），程式暫以 50 為上限。

## 方法

`tools/balance_sim.js` 用遊戲真正的規則（戰鬥、體力、獎勵、抽蛋、升級進化）模擬三類學生玩一個學年（36 週），每類跑 9 次取中位數。題目為假題，答對與否按答對率擲骰。每日第一場先打「今日限定」，之後按玩家等級揀難度。每日任務、每週任務按 Excel 獎勵計算；有寶石就抽角色，有金幣就升級隊員，夠材料就進化。

重新產生：

```
./scripts/jsc.sh tools/balance_sim.js
./scripts/jsc.sh tools/balance_sim.js -- before
```

## 發現的問題（調整前）

1. **傳說核心卡死二階進化**：傳說核心只會在「究極」關及星期日限定關掉落。輕度及一般學生（不玩究極、星期日不玩）整個學年都**做不到二階進化**，隊長停在 Lv 20。
2. **究極關傳說核心過多**：投入型學生一年囤積近 1,900 個，用不完。
3. **金幣不分難度**：簡單和究極勝出都是 30 金幣，沒有挑戰較難關卡的誘因。
4. **開局慢**：新玩家 0 寶石，首次抽蛋要等完成任務；升級亦沒有寶石。
5. **保底太遠**：80 抽保底，以每週約 4 抽計，要接近 20 週。
6. **體力從未不足**：三類學生都沒有因體力不足而轉練習模式——符合 Excel「不限制學習」的原意，暫不需要改。
7. **戰鬥偏易**：答對率 65% 仍有約九成勝率。對學習動機有利，暫不改。

## 已套用的調整

| 項目 | 現時 | 建議 |
|---|---|---|
| 勝出金幣 | 一律 30 | 簡單 20／中等 35／困難 50／究極 70 |
| 升級寶石 | 0 | 每升 1 級 +5 寶石 |
| 開局寶石 | 0 | 30（即可抽 3 次） |
| SSR 保底 | 80 抽（Excel Pools 表） | 50 抽（需同步改 Excel） |
| 傳說核心 | 只限究極／星期日 | 另加：中等勝出 8%、困難勝出 25% 機會得 1 個 |

效果：一般學生第 9 週二階、第 22 週三階進化；輕度學生第 21 週可二階進化；首個 SSR 平均提早。投入型學生仍然較快，但金幣、寶石不會失控。

## 第二輪平衡（2026-11-01）

狀態：CONFIRMED 並已套用（用戶：「套用建議數值」）。檢視時發現加入隊伍人數加成、UR 副本及答題衝刺後，以下 4 個問題：

1. **隊伍變強後答錯也會贏**：Boss 血量固定，隊伍攻擊由 95 升到 327。只答對 65% 的學生，中期 5 人隊伍打 DSE 究極勝率 97%、帝王試煉最難 100%，可以不識答題也拿到 UR「IT帝」。
2. **答題衝刺 UR 裝備太快**：40 碎片，答對 85% 的學生 4 日、75% 的學生 10 日便合成，比 UR 角色（最少約 4 週）容易得多。
3. **傳說核心囤積**：究極每次必得，投入型學生一年囤積約 1,900 個（全遊戲最多只需約 150 個）。
4. **裝備盲盒沒有保底**：Excel 寫 80 抽，但程式從未執行裝備保底。
