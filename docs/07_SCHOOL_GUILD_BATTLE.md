# 校際公會模式：學校 VS 學校（新需求 2026-10-30）

## 核心概念 [使用者確認]
- 加入**公會模式**，以「校與校之間 Battle」為主要想像。公會代表學校的團體歸屬；玩家可為學校貢獻學習戰績。
- 這是新增功能方向，**詳細競技規則未經用戶確定**。請先製作設計提案、原型與測試，不應立即建構正式學生登入或真實排行榜。

## 候選 MVP 方案 [建議，不是已批准規則]
- 非即時 **School Guild League**：各校學生在同一季、相同 Topic／難度題池挑戰共同 Boss。
- 每人每日有限有效挑戰次數；正確率、完成度及速度共同決定個人成績，但速度權重低以免偏離學習價值。
- 學校分數建議用**每校前 N 名或合資格參與者平均／截尾平均**，避免大校只靠人數佔優。可提供不同校規模分組。
- 每季可設：校際 Boss、Topic 主題周、兩校友誼賽。戰報呈現學校總進度、個人成就，但預設不公開個人身份。
- 校內公會有校徽（需授權）、校名、校隊進度、貢獻紀錄及勳章；未核准前用虛構學校與佔位校徽。
- 學生可在賽後獲得題目解說與薄弱 Topic 複習，不單追求快答。

## 安全、公平、治理 [強制設計門檻]
- 中學生可能未成年，預設暱稱制、最小化收集個資、不得公開真名／學號／班別／學校電郵；需設計校方身分核實與教師管理員流程。
- 防止冒充學校、跨校惡意訊息、刷題、重複帳號、內鬼及作弊；初版**不做公開聊天／私訊**。
- 全校公會邀請、資料分享與對外展示要有學校授權；未取得授權不能使用真實學校名稱／校徽作公開內容。
- 教師管理面板：邀請／撤銷成員、舉報及取消資格、競賽監察、保留及刪除資料。
- 不應讓課金、稀有角色／裝備或 AI 提示影響學校競賽公平；比賽使用標準化隊伍或禁用增益道具，請提出方案讓用戶選擇。
- 競賽資料需有伺服器端判分、題目抽取規則、反作弊與稽核，不能只信任手機端分數。

## 待用戶決定 [OPEN_DECISION]
1. 公會等同一所學校，還是每校可設多支隊伍？
2. 非同步 Boss 賽、即時校際 PK，或兩者皆要（建議先非同步）？
3. 如何驗證學生的學校資格？學校電郵／老師邀請碼／校方後台？
4. 競賽按人數、平均分、前 N 名，或學校規模分組？
5. 個人是否允許跨校轉會？賽季多久？
6. 獎勵僅外觀／稱號，還是涉及 RPG 遊戲收益？建議避免 pay-to-win。
7. 校際排行榜是否公開，如何保護未成年人與學校名譽？

## 推進順序
- Phase 1 先做單人 Boss 答題，保持 MVP 可玩。
- Phase 2 出**用虛構學校及假資料**的公會 UI／校際 Boss 積分展示 demo，讓用戶決定規則。
- Phase 4 經授權才接入真實學校、登入、伺服器判分、賽季、後台和反作弊。
- 測試校際公平性：不同學校參與人數、延遲、跨裝置重試、答題中斷、時區／賽季重置。

## 用戶確認的公會規則（2026-10-30）[CONFIRMED]
取代上文「前 N 名平均／避免大校佔優」的候選方案。
- **建立**：玩家以自己名義建立公會；理想是每間學校建立一個。
- **公會副本（Raid Boss）**：Boss 血量遠高於單人關卡；所有會員的傷害從同一個 Boss 總血量中扣除。
- **作答**：每次挑戰限時，限時內盡量作答；答對造成傷害，答錯不造成傷害。
- **次數**：每位會員每天只可挑戰一次。
- **週結**：以每週公會「攻擊總量」排名；人數愈多的公會愈有利，屬刻意設計。
